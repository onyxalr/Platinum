# Platinum

**Platinum** — локальный музыкальный плеер для Linux с премиальным интерфейсом на React Native. Музыка ищется и играет через локальный музыкальный движок, а библиотека, аккаунты, плейлисты, история и офлайн-загрузки хранятся только на компьютере. Без облака, подписок и рекламы.

Renderer работает на React Native Web внутри Electron, backend — Node.js в главном процессе. Наружу уходят только запросы к музыкальному каталогу и LRCLIB.

## Возможности

- **Главная** — персональные подборки, настроения, новинки, проверенные исполнители и продолжение прослушивания.
- **Поиск** — поиск треков с фильтрацией не-музыки, мгновенные подсказки, быстрые фильтры и переходы к исполнителям.
- **Исполнители** — отдельные страницы проверенных артистов с официальным каталогом и воспроизведением всего списка.
- **Импорт** — перенос плейлиста из другого сервиса по ссылке Spotify или через CSV, JSON, M3U и текстовый список.
- **Поток** — бесконечная вертикальная лента рекомендаций.
- **Библиотека** — любимые треки, история, плейлисты и офлайн-загрузки.
- **Плеер** — очередь, shuffle/repeat, seek, громкость, MediaSession и горячие клавиши.
- **Now Playing** — крупная обложка, синхронизированные тексты LRCLIB, очередь, два режима сцены.
- **Кастомизация** — цвета, шрифты, геометрия, материалы, прогресс, состав плеера, эффекты и движение.
- **Два языка дизайна** — строгий **Platinum** и тональный **Material You**.
- **Аккаунты** — локальная регистрация и вход, scrypt-хеши, гостевой режим, сессии на 30 дней.
- **Офлайн** — скачивание аудио в `downloads` и воспроизведение без сети.
- **Русский интерфейс** на всём пути: от входа до настроек и пустых состояний.

## Музыка, а не видео

Поиск и лента не просто отдают первый ответ каталога. Кандидаты проверяются по нескольким признакам:

- канал должен быть artist-owned, **Topic**, **VEVO** или верифицированным;
- фильмы, сериалы, влоги, подкасты, реакции, концерты, DJ-сеты и эпизоды отсекаются по заголовку и каналу;
- загрузки длиннее 12 минут и длинные миксы не попадают в очередь;
- названия вида `Artist - Track` разбираются и очищаются от `Official Audio`, `Lyrics`, `Remastered` и т.п.;
- неоднозначные запросы («Кино», «Свидание») дополняются `official audio`, а жанровые — проверенными каталогами артистов;
- дубликаты схлопываются, совпадения по исполнителю получают приоритет;
- видео-версии получают штраф, поэтому аудио и официальные загрузки звучат раньше.

Так случайные ролики и фильмы не превращаются в треки, а поиск остаётся музыкальным.

## Импорт из других сервисов

- Публичная ссылка Spotify на плейлист, альбом или трек читается через открытые метаданные страницы.
- Apple Music и Яндекс Музыка поддерживаются через экспорт плейлиста в CSV/JSON или вставку списка.
- Понимаются CSV/TSV, JSON, M3U/M3U8 и обычный текст вида `Исполнитель — Название`.
- Каждый трек сопоставляется с официальным каталогом по названию, исполнителю и длительности.
- Совпадения сохраняются в новый плейлист; ненайденные строки показываются в отчёте.
- Разбор и сопоставление выполняются локально, без загрузки аккаунта и cookies.

## Дизайн и кастомизация

Внешний вид полностью собирается из runtime-токенов: ни один экран не зашит в один пресет.

- **Палитры** — Platinum, светлая, noir, porcelain, aurora и собственные цвета.
- **Материалы** — стекло, зерно, размытие, свечение и интенсивность фона.
- **Типографика** — Unbounded для бренда и заголовков, Inter, Manrope, Golos Text, Onest, Rubik, Montserrat, Cormorant Garamond, Lora и Instrument Serif для остального.
- **Макет** — рельс или панель, слева или справа, ширина навигации, плотность, радиусы, ширина контента.
- **Эффекты** — `clean`, `cinematic`, `neon`, `aurora`; совместимы с performance mode и reduced motion.
- **Плеер** — плавающий или панельный, классический или компактный; высота, радиус, размер обложки и кнопок, материал, форма обложки, стиль прогресса, время, акцентный play и видимость каждого элемента.
- **Now Playing** — сцена с боковой панелью или чистый фокус, масштаб обложки, живой фон из обложки.
- **Движение** — скорость и характер анимаций, отдельный режим для слабых машин.

Все настройки применяются сразу и сохраняются локально. Есть сброс к пресету, случайная палитра и отдельная вкладка «Плеер» с живым превью.

## Производительность

Platinum рассчитан на ноутбуки уровня Acer Aspire с 8 ГБ ОЗУ и Linux на Wayland.

- В Electron отключены фоновые сервисы Chromium, magic spellcheck и лишние фоновые задачи; включены кэш V8 и Wayland hint.
- Настройки загружаются отдельным чанком только при открытии.
- Обложки запрашиваются в размере, соответствующем карточке, а не в максимальном разрешении.
- Performance mode убирает тяжёлые blur/ambient-слои и упрощает сцену, сохраняя структуру интерфейса.
- `prefers-reduced-motion` уважается, а все эффекты можно отключить вручную.
- Аудио идёт через локальный HTTP с `Range`, поэтому seek не зависит от рендера внешнего плеера.

## Требования

- Linux x64 или arm64, X11 или Wayland.
- Node.js **22.12+** и npm.
- GTK/X11/Wayland-библиотеки для Electron (в большинстве дистрибутивов уже установлены).
- Сеть для музыкального каталога и LRCLIB.

## Запуск

```bash
npm install
npm run dev
```

`npm run dev` собирает main/preload, поднимает Vite на `127.0.0.1:5273` и запускает Electron. При старте поверх рабочего стола показывается нативный splash с логотипом Platinum, затем открывается основное окно.

Проверка типов и production-сборка:

```bash
npm run build
```

Запуск собранного приложения без установки:

```bash
npm start
```

## yt-dlp

Platinum не требует системной установки `yt-dlp`, но использует её, если она есть. Порядок поиска:

1. `PLATINUM_YTDLP` — явный путь.
2. `~/.config/Platinum/bin/yt-dlp` — скачанный приложением бинарник.
3. `resources/bin/yt-dlp` — опционально упакованный вместе с приложением.
4. `/usr/local/bin/yt-dlp`, `/usr/bin/yt-dlp`, `~/.local/bin/yt-dlp`.

Если бинарник не найден, приложение скачает standalone-сборку с GitHub в фоне и покажет прогресс в настройках/аккаунте.

Для релизной сборки можно заранее положить бинарник в пакет:

```bash
npm run fetch:ytdlp
npm run dist
```

Скрипт поддерживает `--force` и `YTDLP_VERSION`. Бинарник в `resources/bin` не коммитится.

## Сборка релиза

```bash
npm run dist
```

Результат — AppImage и `.deb` в `release/`. Иконка и desktop-метаданные находятся в `build/` и `package.json`.

Если в системе не установлены зависимости для `fpm`/AppImage, electron-builder скачает свои инструменты при первой сборке.

## Где хранятся данные

В Linux по умолчанию:

```text
~/.config/Platinum/
├── platinum.db          # аккаунты, сессии, лайки, история, плейлисты, загрузки
├── downloads/           # офлайн-аудио
└── bin/yt-dlp           # автоматически скачанный движок
```

База создаётся при первом запуске. Аккаунты, пароли, история и плейлисты не покидают устройство. Пароли хранятся как scrypt-хеши, токены сессий — как SHA-256-хеши.

## Архитектура

```text
electron/
  main.ts        окно, нативный splash, Wayland/Chromium flags, IPC, жизненный цикл
  splash.ts      самодостаточный always-on-top splash с логотипом
  preload.ts     безопасный bridge window.platinum
  server.ts      локальный HTTP API, Range-стриминг, загрузки, подборки, артисты, импорт
  db.ts          SQLite-схема и запросы
  auth.ts        регистрация, вход, сессии, гостевой режим
  ytdlp.ts       поиск, фильтрация, артисты, сопоставление импорта, download, обновление
  import.ts      разбор ссылок Spotify, CSV/TSV, JSON, M3U и текстовых списков
  lyrics.ts      LRCLIB + LRC-парсер
src/
  screens/       Главная, Поиск, Поток, Библиотека, Плейлист, Исполнитель, Аккаунт, Вход
  components/    плеер, Now Playing, тексты, модалки (включая импорт), UI-примитивы
  store/         Zustand: auth, player, ui, runtime, appearance
  audio/         HTMLAudioElement + MediaSession
  lib/           API-клиент, форматтеры, RNW-адаптер
shared/          общие типы main/renderer
```

Локальный сервер слушает случайный порт на `127.0.0.1`; renderer узнаёт адрес через preload. Аудио проксируется через `/stream/:id` с поддержкой `Range`, поэтому seek работает без прямого доступа renderer к источнику. Скачанные файлы отдаются через `/media/:id`.

## Горячие клавиши

- `Space` — play/pause (когда фокус не в поле ввода).
- `←` / `→` — перемотка на 5 секунд.
- `/` — фокус на поиске.
- `L` — любимое, `M` — mute, `F` — Поток.
- `Esc` — закрыть модалку или Now Playing.

## Приватность и ограничения

- Пароли не хранятся в открытом виде. Сессии живут 30 дней и отзываются при выходе.
- Никакой телеметрии и внешней аналитики. Сеть используется только для поиска и стриминга музыки, LRCLIB и обновления `yt-dlp`.
- Источники каталога могут менять форматы и ограничивать запросы; обновляйте `yt-dlp` из настроек.
- Некоторые треки недоступны для прямого стриминга или не имеют текста на LRCLIB.
- Приложение не обходит региональные ограничения и не предназначено для массового скачивания контента.
- Музыка принадлежит правообладателям. Используйте приложение для личного прослушивания.
